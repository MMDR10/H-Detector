# 🌊 ENSO Watch — El Niño 簡易預警工具

雙擊即睇。兩種玩法：🖥️ HTML 網頁版（手機都得）或 🐍 Python 命令列。

## 係咩嚟？

一個 Python 小程式，幫你睇實 El Niño / La Niña（聖嬰／反聖嬰）嘅最新狀態。分析 NOAA 75 年歷史數據，用兩個數學方法偵測異常信號。

**適合：** 漁民、沿海居民、農民、任何受 ENSO 影響嘅人。

## 點用？

### 🖥️ 網頁版（推薦 — 零門檻）

**雙擊 `enso_dashboard.html`** 就得！手機、平板、電腦全部支援。唔使裝任何嘢。

你會睇到：
- 🟢🟡🔴 巨型預警燈
- ΔH 歷史趨勢圖
- 近 3 年 ONI 走勢圖
- 詳細解釋

### 🐍 Python 命令列版

```bash
python enso_watch.py
```

就咁多。你會睇到：

```

   ΔH = -0.18
   狀態：⚠️ 反轉！

─── 🔍 χ_eff 結構剛性 ───
   當前階段：中性（Neutral）
   χ_eff = 34.8  ✅ 正常

═══ 🎯 綜合預警：🟡 黃色 ═══
```

## 點解要睇？

| 信號 | 意思 | 做咩好 |
|------|------|--------|
| 🟢 綠色 | 一切正常 | 每月 check 一次 |
| 🟡 黃色 | 有一個異常 | 留意 3-6 個月內變化 |
| 🔴 紅色 | 兩個異常 | 高度警覺，可能有大事件 |

## 原理（簡化版）

兩個探測器：

1. **Core-Shell（深層結構）**：將海水溫度數據拆成「長期趨勢」同「短期波動」。當深層結構反轉（ΔH < 0），歷史上 1996 年出現過，6 個月後就係 1997 超級 El Niño。

2. **χ_eff（結構剛性）**：量度系統對外界干擾嘅敏感度。結構太剛硬或太柔軟都係異常信號。
